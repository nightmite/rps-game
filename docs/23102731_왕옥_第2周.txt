一、这是什么
----------------------------------------------------------------
把一个用 C++ 写的控制台石头剪刀布，改造成可以直接在浏览器里玩的
网页小游戏：有卡通可爱的手势卡片、倒数动画、翻牌、礼花、音效、
战绩统计，电脑还会"记住你最近几手"和你斗智。

第 1 周的程序是"能跑对"，第 2 周的目标是"好玩、好看、手机也能玩"。
规则内核（谁赢谁输、电脑怎么出拳）完全沿用第 1 周的设计，
只把界面从字符终端换成了 HTML + CSS + 动画。

二、第 1 周的核心功能，一个都没丢
----------------------------------------------------------------
 第 1 周（C++ 控制台）              第 2 周（网页）
 ---------------------------------  -----------------------------------
 菜单：经典对战 / 无限练习 / 玩法      顶栏按钮：先赢 3 局 / 无限练习 / 玩法说明
 键盘输入 1 / 2 / 3 出拳              三个大按钮点击出拳，或按键盘 1 / 2 / 3
 双方手势用文字卡片显示               两张 3D 卡片：背面问号，翻过来是手绘图
 电脑出拳三帧动画（. .. ...）         倒数"石头、剪刀、布、出拳！"+ 电脑卡抖动
 会读心的电脑：70% 随机 + 30% 反制     难度三档：简单 90/10、普通 70/30、困难 40/60
 近期战绩 8 条 + 生涯战绩存档         近期 8 回合胶囊 + 趋势条 + 生涯战绩（浏览器本地保存）

 自测模式 --selftest                  页面内置 RpsDemo.selfTest()（规则 / 胜率 / 存档自检）

三、这一周新做 / 改进的 9 个功能（对应"至少改进或新增 1 项"）
----------------------------------------------------------------
1. 卡通可爱视觉
   奶油底色 + 粉色/天蓝配色，圆角卡片、双层柔和投影；玩家一侧是粉色卡片，
   电脑一侧是蓝色卡片，左右一眼分得清。所有手势都是手绘 SVG（不是 emoji）：
   握拳（石头）、伸出食指中指（剪刀）、张开五指（布），都带小脸和腮红。

2. 丝滑的翻牌动画
   卡片有 3D 透视，点下去玩家卡先翻转（0.34 秒），电脑卡抖一下再翻。
   只用 transform 和 opacity 做动画，不触发页面重排，所以不卡。
   出拳按钮悬停会轻轻抬起并回弹（cubic-bezier 弹性缓动）。

3. "石头、剪刀、布"倒数遮罩
   出拳后屏幕中央依次弹出「石头 → 剪刀 → 布 → 出拳！」，每个字 0.23 秒，
   带缩放回弹和音效，把等待的 1 秒变成有节奏的仪式感。

4. 难度三档（替换第 1 周写死的 30%）
   简单：电脑只有 10% 概率反制你，适合新手；
   普通：30%，接近第 1 周手感；
   困难：60%，而且记得你最近 8 手（第 1 周是 5 手），会明显"读心"。

5. 连胜火焰 + 最佳连胜
   连胜 2 场以上，火焰图标点亮并跳动、连胜胶囊发光；右侧小圆点显示连胜进度，
   打破纪录时刷新"最佳"。

6. 礼花 + 音效
   赢一局在玩家卡片位置爆出 26 颗彩纸粒子（canvas + requestAnimationFrame，
   带重力和淡出），连胜时全屏再炸一次；输一局页面轻微震一下。
   音效全部用 Web Audio 现场合成（不加载音频文件）：点击、倒数、翻牌、
   赢、输、平、连胜、结算号角，右上角可一键静音。

7. 战绩自动保存 + 趋势条
   生涯战绩（胜/负/平/胜率/最佳连胜）存在浏览器 localStorage，
   关掉网页再回来还在；最近 8 回合用"手势图标 + 颜色胶囊"显示，下面一条
   趋势条按顺序显示近 8 局结果。点"重置战绩"可清零。

8. 手机也能玩（响应式）
   760px 以下换紧凑布局，420px 以下隐藏英文和按键提示，只留三张大手势按钮，
   实测 390×844 的竖屏截图排版正常。

9. 战绩面板（第 2 次迭代新增）
   结算页点「看看战绩」不再只是关掉弹窗，而是打开一个真正的战绩面板：
   上半部分 6 个格子（胜 / 负 / 平 / 胜率 / 最佳连胜 / 总回合），
   下半部分列出本局最近 8 回合的"你出什么 vs 电脑出什么 + 胜负"，
   赢绿、负红、平灰；底部可以直接重置战绩。关掉面板后自动开新的一局。
   屏幕小于 760px 时自动改成紧凑布局，小于 420px 时三张出拳按钮仍是并排
   （手指最容易点），卡片缩小、键盘提示隐藏。已用 390×844 的手机视口验证。

四、还顺手做的小细节
----------------------------------------------------------------
- 结算弹层：一局结束后弹出本局比分、回合数、平局数、本局最长连胜，
  背景高斯模糊，按钮是"再来一局 / 看看战绩"。
- 电脑的提示文字会变化：赢时说"漂亮！继续压住它"，输时说
  "它好像猜到你了…换个手势试试"，平局说"势均力敌，再来一手"。
- 结果条会显示"你出剪刀，电脑出布。漂亮！"，把这一手的因果讲清楚。
- 尊重系统设置：用户开了"减少动态效果"，所有动画自动关掉。
- 内置页面自测：按 F12 打开控制台输入 RpsDemo.selfTest() 就能跑一遍
  规则判定、胜率区间、存档往返等 6 项检查，方便验收。

五、技术实现（纯前端，无框架、无构建、无依赖）
----------------------------------------------------------------
文件结构：
  week2_web/
    index.html        页面结构 + 手绘 SVG 手势图（<defs> 里定义三只手）
    css/style.css     全部样式与动画（约 900 行）
    js/game.js        规则内核：判定、计分、连胜、近期战绩、生涯存档、自测
    js/ai.js          电脑出拳策略：三档难度 + "记住你最近几手"的反制逻辑
    js/sound.js       Web Audio 合成音效
    js/ui.js          界面与动画流程：翻牌、倒数、礼花、结算、按钮事件

关键设计：
1. 三层分离：game.js 只管规则（不碰 DOM），ai.js 只管出拳策略，
   ui.js 只管画面。所以规则内核和第 1 周的 C++ 版是一一对应的，
   以后换成别的界面也不用改规则。
2. 结算放在动画之后：先播倒数、再抖动、最后才真正 playRound()，
   所以比分不会在动画播完之前就跳，看起来才顺。
3. 动画只用 transform / opacity，统一弹性缓动 cubic-bezier(.34,1.56,.64,1)，
   时长 150~400 毫秒（超过 600 毫秒就会觉得卡）。
4. 战绩用 localStorage 存一行 JSON，键名 rps_23102731_v1，和第 1 周
   的 record.txt 思路一致：写进去、下次读回来，坏了就用默认值兜底。
